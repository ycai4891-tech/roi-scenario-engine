# ROI Scenario Engine

Generates 48 commercial ROI scenarios across subscription terms, benefit cases and
deployment scale, returning net benefit, ROI and payback period for each.

## Method
4 subscription terms x 3 benefit cases x 4 deployment sizes = 48 scenarios.
Each combination computes total cost (hardware, setup, subscription), total benefit
over a 3-year contract, and the resulting ROI and payback period.

## Why
Sales teams need to answer "when does this pay back", not just quote a price.
A scenario grid answers that for any deal shape in seconds.

## Tools
Python · Pandas · matplotlib

Structure based on a commercial ROI model I built during an internship.
